JSON API

Everything you can do in the pages you can do over HTTP. The full description is an OpenAPI 3.1 document: /api/v1/openapi.yaml.

Authentication

curl -s -X POST localhost:8080/api/v1/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"email":"organizer@dogfood.local","password":"dogfood-demo"}'
# → {"token": "…"}; then send  Authorization: Bearer <token>

Or create a long-lived token on your account page.

Examples

# public gallery
curl -s 'localhost:8080/api/v1/events/evt_01/projects?q=signal'

# your own scores (judge)
curl -s localhost:8080/api/v1/judge/scores -H "Authorization: Bearer $TOKEN"

# another judge's scores: 403 unless you organize that event
curl -si 'localhost:8080/api/v1/judge/scores?judge=jdg_26' -H "Authorization: Bearer $OTHER_JUDGE"

# normalized results with uncertainty (organizer)
curl -s localhost:8080/api/v1/events/evt_01/results -H "Authorization: Bearer $TOKEN"

# export everything, import it elsewhere
curl -s localhost:8080/api/v1/events/evt_01/export.json -H "Authorization: Bearer $TOKEN" > event.json
curl -s -X POST otherhost:8080/api/v1/import -H "Authorization: Bearer $ADMIN" --data-binary @event.json

Errors

Errors are JSON: {"error": {"code": "submissions_closed", "message": "…"}} with 400, 401, 403, 404, 409 or 429.

Webhooks

Organizers register URLs per event (Settings → Webhooks). Deliveries are POSTed as JSON with X-Dogfood-Signature: sha256=<HMAC of body with the webhook secret>, retried with exponential backoff up to 8 times.
